# 네이버 쇼핑 키워드 순위 조회 (엑셀)

엑셀에 키워드를 넣고 버튼(매크로)을 누르면 **네이버 쇼핑 검색에서 내 상품이 몇 위인지** 알려줍니다.

| 파일 | 설명 |
|---|---|
| `순위조회_양식.xlsx` | 엑셀 양식 (순위조회 / 설정 / 기록 시트) |
| `NaverRank.bas` | 순위 조회 VBA 매크로 |

> Windows용 엑셀 기준입니다. (Mac 엑셀은 통신 기능이 달라 동작하지 않습니다.)

## 1. 네이버 API 키 발급 (무료, 최초 1회)

1. https://developers.naver.com → 로그인 → **Application → 애플리케이션 등록**
2. 사용 API: **검색** 선택, 환경: **WEB 설정** 에 `http://localhost` 입력
3. 등록 후 나오는 **Client ID / Client Secret** 복사

## 2. 엑셀 준비 (최초 1회)

1. `순위조회_양식.xlsx` 열기 → **다른 이름으로 저장 → "Excel 매크로 사용 통합 문서(*.xlsm)"**
2. `Alt + F11` (VBA 편집기) → **파일 → 파일 가져오기** → `NaverRank.bas` 선택 → 편집기 닫기
3. **설정** 시트에 입력
   - `Client ID`, `Client Secret`
   - `내 스토어명` : 네이버쇼핑 검색결과에 보이는 판매처 이름 (띄어쓰기/대소문자 무시)
   - `내 상품ID` : (선택) 여러 개면 쉼표로 구분
4. (선택) 버튼 만들기: **개발 도구 → 삽입 → 단추** → 매크로 `CheckRanks` 연결

## 3. 사용

1. **순위조회** 시트 A열(2행부터)에 키워드 입력
2. 버튼 클릭, 또는 `Alt + F8` → `CheckRanks` 실행
3. 결과

| 키워드 | 순위 | 화면 위치 | 상품명 | 가격 | 상품ID | 조회시간 | 비고 |
|---|---|---|---|---|---|---|---|
| 캠핑의자 | 57 | 2페이지 17번째 | ... | 39,000 | 8xxxxxxxx | ... | |
| 접이식 의자 | 순위밖 | | | | | ... | 1000위 안에 없음 |

- 조회할 때마다 **기록** 시트에 날짜별로 쌓여서 순위 변화를 볼 수 있습니다.

## 참고 / 한계

- 네이버 공식 **쇼핑 검색 API**(정확도순)를 사용합니다. 광고 상품은 포함되지 않고,
  실제 화면 순위와 몇 칸 정도 차이가 날 수 있습니다.
- API 제한상 **최대 1000위**까지만 확인 가능하며, 키워드 1개당 최대 10회 호출합니다(하루 25,000회 한도).
- 가격비교(카탈로그)로 묶인 상품은 판매처가 "네이버"로 나와 스토어명으로는 안 잡힙니다.
  이 경우 `내 상품ID`에 **카탈로그 ID**를 넣으면 찾을 수 있습니다.
