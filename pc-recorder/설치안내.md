# 쇼츠 컷 자동 녹화 설치 안내 (Windows 11)

매일 새벽 4시 메일이 나갈 때, 그날 대본의 컷 목록이 GitHub 저장소의 `clips/latest.json`에 올라갑니다.
이 PC는 새벽 5시에 그 목록을 받아서 컷마다 OBS로 녹화하고, 아래처럼 저장합니다.

```
D:\쇼츠녹화\2026-10-01\조나단\01_컷1_훅.mp4
                            \02_컷2_기.mp4
                            \대본.txt
```

처음 한 번만 아래 순서대로 설정하면 됩니다. (30분~1시간)

---

## 1. 프로그램 설치 (모두 무료)

1. **크롬**: 이미 있으면 그대로 사용
2. **Python**: https://www.python.org/downloads/ 에서 설치
   - 설치 첫 화면에서 **"Add python.exe to PATH"** 를 꼭 체크하세요.
3. **OBS Studio**: https://obsproject.com/ 에서 설치 (기본 경로 그대로)

## 2. 녹화 스크립트 받기

1. GitHub 저장소 `parkgyeongmuk/test` 에서 브랜치 `claude/confident-pasteur-fi9mov` 를 선택
2. **Code → Download ZIP** 으로 받아서 압축을 풀고, `pc-recorder` 폴더를 `C:\쇼츠녹화봇` 으로 복사
3. `C:\쇼츠녹화봇` 폴더 주소창에 `cmd` 입력 후 엔터, 아래 명령 실행

```
pip install -r requirements.txt
```

## 3. OBS 설정

1. OBS 실행 → 처음 뜨는 자동 구성 마법사는 **"녹화에 최적화"** 선택
2. **도구 → WebSocket 서버 설정**
   - "WebSocket 서버 사용" 체크
   - "비밀번호 표시"를 눌러 비밀번호를 복사해 두기 (4단계에서 사용)
   - 포트는 4455 그대로
3. **장면 만들기**
   - 소스 목록의 **+ → 디스플레이 캡처** 추가 → 녹화할 모니터 선택 → **"커서 캡처" 체크 해제**
   - 오디오 믹서에 "데스크톱 오디오"가 있는지 확인 (영상 소리가 여기로 녹음됨)
4. **설정 → 출력 → 녹화**
   - 녹화 형식: **MP4** (또는 하이브리드 MP4)
   - 녹화 경로는 아무거나 괜찮아요. 스크립트가 끝나면 알맞은 폴더로 옮깁니다.
5. **설정 → 비디오**: 기본(캔버스) 해상도와 출력 해상도 **1920x1080**

## 4. 설정 파일 만들기

1. `config.example.json` 을 복사해서 이름을 **`config.json`** 으로 바꾸기
2. 메모장으로 열어서 두 곳을 채우기
   - `obs_password`: 3단계에서 복사한 OBS 비밀번호
   - `github_token`: 아래에서 만드는 토큰
   - 저장 위치를 바꾸려면 `save_dir` 수정 (예: `"C:\\Users\\내이름\\Videos\\쇼츠녹화"`, 역슬래시는 두 번씩)

### GitHub 읽기 전용 토큰 만들기
1. GitHub 로그인 → 오른쪽 위 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. Token name: `쇼츠녹화`, Expiration: 원하는 기간 (예: 1년)
3. **Repository access → Only select repositories → `parkgyeongmuk/test`**
4. **Permissions → Repository permissions → Contents: Read-only** (나머지는 건드리지 않기)
5. Generate → 나온 토큰(`github_pat_...`)을 `config.json`의 `github_token` 에 붙여넣기

> 토큰은 비밀번호와 같아요. 다른 사람이나 채팅에 보여주지 마세요.

## 5. 시험 실행

`C:\쇼츠녹화봇` 에서 cmd를 열고:

```
python record.py --dry-run
```
→ 오늘(또는 가장 최근) 컷 목록이 보이면 GitHub 연결 성공

```
python record.py --test
```
→ 크롬이 전체화면으로 열리고, 첫 컷 하나를 녹화해서 저장 폴더에 넣습니다.
저장된 파일을 열어 **화면과 소리**가 제대로 녹화됐는지 확인하세요.

- 녹화는 평소 크롬과 분리된 **전용 크롬 프로필**로 해요. YouTube가 로그인을 요구하면 `python record.py --login` 을 실행하고, 뜬 크롬 창에서 구글 계정으로 로그인한 뒤 창을 닫으세요. 한 번 하면 계속 유지돼요.
- 문제가 있으면 `record.log` 내용을 알려주세요.

## 6. 매일 자동 실행 등록 (작업 스케줄러)

1. 시작 → **작업 스케줄러** 실행 → 오른쪽 **작업 만들기**
2. **일반** 탭
   - 이름: `쇼츠 자동 녹화`
   - **"사용자가 로그온할 때만 실행"** 선택 (화면이 있어야 녹화돼요)
3. **트리거** 탭 → 새로 만들기
   - 매주, 시작 시간 **오전 5:00**, 월~금 체크
4. **동작** 탭 → 새로 만들기
   - 프로그램: `C:\쇼츠녹화봇\실행.bat`
   - 시작 위치: `C:\쇼츠녹화봇`
5. **조건** 탭
   - **"작업을 실행하기 위해 절전 모드 종료" 체크**
   - "컴퓨터의 AC 전원이 켜져 있는 경우에만 작업 시작" 은 노트북이면 체크 해제해도 됨
6. 확인

## 7. 윈도우 설정 (중요)

녹화는 화면에 보이는 걸 찍기 때문에, **잠금 화면이면 잠금 화면이 녹화돼요.**

- **설정 → 계정 → 로그인 옵션 → "다시 로그인해야 하는 경우"를 "안 함"** 으로
- **설정 → 개인 설정 → 잠금 화면 → 화면 보호기 → 없음**
- **설정 → 시스템 → 전원 → 화면 끄기는 괜찮지만, 절전 모드는 새벽 5시에 깨어나도록** 위 5단계의 "절전 모드 종료"를 체크
- **전원 옵션 → 고급 설정 → 절전 → "절전 모드 해제 타이머 허용" → 사용**
- 윈도우 업데이트 재시작 뒤에는 로그인이 풀릴 수 있으니, 가끔 로그인 상태인지 확인하세요.

## 참고
- **광고**: 프리미엄이 아니라서, 영상 앞 광고는 건너뛰거나 끝날 때까지 기다린 뒤 녹화해요. 녹화 중에 광고가 끼면 그 컷은 지우고 최대 3번 다시 녹화해요.
- **여유 시간**: 자막 타임코드가 1~2초 어긋날 수 있어서 컷 앞뒤로 1.5초씩 더 녹화해요. (`pad_before`, `pad_after` 로 조절)
- **녹화 시간**: 영상 5개, 컷 약 20개 기준으로 10~15분 정도 걸려요. 그동안 PC를 건드리지 마세요.
- **실패 기록**: 모든 과정은 `record.log` 에 남아요.
