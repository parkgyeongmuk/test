# 스마트스토어 상품명 만들기 (이셀러스 엑셀)

사장님(사용자)이 이셀러스 엑셀을 주면, **상품명은 Claude가 직접 판단해서 쓰고**, 숫자 조회와 엑셀 처리는 스크립트가 한다.
OpenAI 등 유료 API는 쓰지 않는다. 사용자에게는 쉬운 한국어로, 진행 상황을 짧게 알린다.

## 파이썬 실행
- 스크립트 폴더: 이 SKILL.md가 있는 폴더의 `scripts/` (PC 설치본은 `C:\Users\qkrru\.claude\skills\smartstore-titles\scripts`, 저장소에서는 `.claude/skills/smartstore-titles/scripts`).
- Windows: `py -3 -I <스크립트>`로 실행한다. `py`가 없으면 `python -I`. Microsoft Store 별칭 python은 AppData 경로를 못 읽는 경우가 있어 `py`를 우선한다.
- 클라우드 세션(Linux/Mac): 아래 `py -3`를 모두 `python3`로 바꿔 실행한다.
- 필요한 패키지: xlrd==2.0.2, xlutils, xlwt, openpyxl. 없으면 사용자에게 알리고 `py -3 -m pip install xlrd==2.0.2 xlutils xlwt openpyxl`(클라우드는 `python3 -m pip install ...`) 실행 허락을 받는다.
- 클라우드 세션에서는 사용자가 엑셀을 첨부하면 업로드 폴더에 들어온다. 원본 옆 저장이 아니라 결과 파일을 사용자에게 파일로 보내준다(SendUserFile 등).
- 한글 출력이 깨지면 `$env:PYTHONIOENCODING="utf-8"`을 먼저 설정한다.
- 후보·상품명 JSON 파일은 임시 폴더(세션 scratchpad가 있으면 거기)에 Write 도구로 만든다. 원본 엑셀 폴더에 작업 파일을 남기지 않는다.

## 순서

### 1. 엑셀 읽기
엑셀 경로를 모르면 묻는다. `py -3 -I scripts/extract.py "<엑셀>"`
- 상품별 행 번호, 정리된 상품명(브랜드 제거)과 글자 수, 판매가 변경 예정값, 원산지, 옵션명을 보여준다.
- 파일 이름에 `_상품정보수정`이 있으면 이미 수정한 파일일 수 있다 → 판매가가 또 25% 오르니 원본인지 꼭 확인한다.

### 한 번에 끝까지 (100개 이상도)
- 사용자가 한 번 요청하면 **엑셀의 모든 상품을 끝까지 처리**한다. 중간에 "계속할까요?"라고 묻거나 멈추지 않는다.
- 2~3단계는 안에서 20~30개씩 묶어 반복하되, 쓴 상품명은 묶음이 끝날 때마다 상품명 JSON 파일에 **누적 저장**한다(중간에 끊겨도 이어서 할 수 있게).
- 4단계(apply)는 모든 상품이 끝난 뒤 **한 번만** 실행해 엑셀 하나로 저장한다.
- 진행 중에는 "40/100개 완료"처럼 한 줄로만 알린다.

### 2. 상품별 후보 단어 떠올리기 → DB 조회
상품마다:
1. **실제 상품이 뭔지** 상품명으로 판단한다(이미지·상세설명은 안 봄). 옵션명도 사실 근거로 참고한다(예: 옵션명 '에코보냉' → 보냉 OK).
2. **같은 물건을 사람들이 부르는 다른 이름(동의어)** 을 충분히 떠올린다. 가장 중요하다.
   예) 귀이개 → 귀파개, 귀후비개, 귀청소, 귀지제거 / 휴대폰 거치대 → 핸드폰거치대, 폰홀더 / 수건걸이 → 타월걸이, 수건봉
3. 그다음 실제 용도·사용 장소·사용 상황 단어(직장인, 소풍, 캠핑, 욕실, 주방, 정리, 차량용 등).
4. 후보를 `{"행번호": ["후보1", "후보2", ...]}` JSON으로 만들어 `py -3 -I scripts/lookup.py <후보.json>` 실행.
   - 각 후보의 아이템스카우트 검색수/경쟁강도(상품수÷검색수, 낮을수록 좋음)/카테고리, 그리고 첫 두 단어가 들어간 인기 키워드가 나온다.
   - 검색 기록이 있는 동의어를 우선하고, 같은 상품 안에서는 검색수 높고 경쟁강도 낮은 쪽을 앞에 둔다.
   - **아이템스카우트 카테고리는 상품 단위가 아니다.** 같은 카테고리에 다른 상품·상위 품목·브랜드가 섞여 있다(예: 세면대수전/워터탭 카테고리의 아기비데수전·욕실수도꼭지·브랜드 수전, 면봉 카테고리의 끈끈이면봉). 카테고리가 같다고 쓰지 말고, 이 상품과 같은 물건인지 직접 판단한다.

### 3. 상품명 쓰기 규칙
- **기존 상품명 단어를 하나도 빼지 않고 같은 순서로 맨 앞에** 둔다(사장님이 정리한 상품명이다).
- 그 뒤에 동의어 → 용도 단어 순으로 붙여 **공백 포함 30~40자**(목표 32~38자).
- **같은 단어 반복 금지.** 붙은 키워드는 이미 쓴 부분을 빼고 나머지만: '텀블러'가 있으면 '텀블러가방' 대신 '가방'.
  한 단어가 다른 단어 안에 통째로 들어가는 것(홀더/컵홀더), 3글자 이상 겹침(공구거치대/드릴거치대)도 금지. 2글자 조각(걸이·드릴)은 허용.
- 한 글자 단어 금지. 한 단어인 말(귀청소, 발톱긁개)을 쪼개지 않는다.
- **사실이 아닌 말 금지:** 기존 상품명·옵션명에 없는 사용 대상(유아용 등), 소재, 기능(방수·자석·재사용·접이식 등), 색상, 크기, 수량, 숫자.
- 다른 종류의 상품, 부품·소모품, 함께 쓰는 물건, 상위 품목 본체 이름 금지. 브랜드·모델명 금지(config.json의 brands 포함). 과장·판촉 문구 금지(최고, 특가, 인기, 추천, 간편 등).
- **쓸 만한 단어가 모자라면 억지로 채우지 말고 30자 미만으로 둔다.** 결과에 '확인 필요'로 표시돼 사장님이 직접 보충한다.
- 상품명을 `{"행번호": "상품명", ...}` JSON으로 저장한다.

### 4. 네이버 카테고리 고르기
- **새 상품명(가공명) 기준으로** 그 물건 자체를 부르는 이름(2단계에서 찾은 동의어, 예: 귀이개·귀파개·귀후비개)만 모아 `{"행번호": ["이름1", "이름2", ...]}` JSON을 만든다. 용도·장소 단어(캠핑, 욕실 등)는 넣지 않는다.
- `py -3 -I scripts/category.py <물건이름.json> --out <카테고리.json>` 실행. 키워드 DB의 아이템스카우트 '대표 카테고리'(네이버쇼핑 카테고리 경로)를 검색수로 더해 가장 큰 것을 추천하고, 네이버 카테고리 번호(`code`)를 붙인다.
- 대표 카테고리는 그 키워드 상품이 가장 많이 몰린 곳이라 엉뚱할 수 있다(부품·액세서리·상위 품목 카테고리 등). 추천이 이 상품과 같은 물건의 카테고리인지 Claude가 확인하고, 아니면 `py -3 -I scripts/category.py --find <단어들>`로 네이버 카테고리 목록에서 맞는 것을 찾아 카테고리.json의 `code`/`category`를 고친다. 맞는 게 정말 없으면 가장 가까운 것을 고르고 '확인 필요'로 표시한다.
- 엑셀의 원래 `카테고리 번호` 칸(이셀러스 카테고리)은 건드리지 않는다.

### 5. 검사 + 엑셀 저장
`py -3 -I scripts/apply.py "<원본 엑셀>" <상품명.json> --categories <카테고리.json>` (상품명만 바꾸려면 `--names-only` 추가)
- 반복 단어·기존 단어 빠짐·40자 초과·브랜드·과장·원본에 없는 숫자/색상/크기, 목록에 없는 카테고리 번호를 검사한다. 걸리면 저장하지 않고 이유를 보여주니, 고쳐서 다시 실행한다.
- 통과하면 원본 옆에 `<원본이름>_상품정보수정.xls(x)`로 저장한다(원본은 절대 덮어쓰지 않음, 같은 이름이 있으면 `_2`, `_3`).
- 엑셀 수정: 상품명 / 판매가 `ROUND(판매가×1.25, -1)` / 수량 = 옵션 재고 합계 / 원산지 `기타` → `수입/아시아/중국` / **폴더명 = `[네이버 카테고리 번호] 경로`**(사장님이 임시로 보는 칸). 나머지 칸과 다른 시트는 그대로이며, 스크립트가 저장 후 다시 읽어 확인한다.

### 6. 사용자에게 알리기
- 저장 위치, 상품별 새 상품명(글자 수), 추천 네이버 카테고리, '확인 필요' 목록(30자 미만, 카테고리 불확실 등)을 표로 보여준다.
- 동의어 중 검색수가 큰 것이나 경쟁강도가 아주 낮은 키워드처럼 눈에 띄는 근거를 한두 줄로 덧붙인다.
- 판매가는 돌릴 때마다 25% 오르니 **항상 원본 엑셀로** 작업하라고 한 줄 알린다.

## 키워드 DB 갱신 (한 달에 한 번 정도)
사용자가 아이템스카우트에서 새로 받은 엑셀을 주면 `py -3 -I scripts/build_db.py <엑셀들 또는 폴더>`.
기존 DB는 `keyword_db.backup.csv.gz`로 보관된다. 현재 DB: 2026-04~09, 250개 카테고리, 키워드 약 20만 개.

## 네이버 카테고리 목록
`naver_categories.csv.gz`(번호·경로, 약 5,000개)는 공개 목록(github.com/isnow890/naver-search-mcp 의 data/categories.json)에서 만들었다. 최신이 아닐 수 있으니, 결과를 알릴 때 스마트스토어 등록 화면에서 번호가 안 맞으면 경로 이름으로 다시 찾으라고 한 줄 알린다.

## 제외 브랜드 바꾸기
`config.json`의 `brands` 목록을 고친다(사용자가 "OO도 브랜드니까 빼줘"라고 하면 추가).
